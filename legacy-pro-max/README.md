# Legacy Pro Max

**Tagline:** Where Legal Excellence Meets Digital Sophistication

Legacy Pro Max is a premium WordPress theme designed for modern law firms, solo practitioners, and legal consultants. It's built to communicate authority, trust, clarity, and urgency, while delivering a high-performance digital experience that converts visitors into consultations.

## Getting Started

For full documentation, please see the `documentation` directory.

## Core Features

*   **Design System:** Token-based design system with CSS variables and presets for 6 Firm Archetypes.
*   **Typography Engine:** 75+ curated Google Fonts with variable font controls and fluid typography.
*   **Animation & Interaction Engine:** Powered by GSAP for smooth, performant animations.
*   **Visual Customizer 2.0:** Extend the WordPress Customizer with advanced controls and a live accessibility validator.
*   **Section Builder:** Modular, reusable sections built as Gutenberg blocks.
*   **Legal-Specific Features:** Attorney credential display, compliance disclaimers, and more.
*   **Conversion System:** Smart CTA logic, exit-intent detection, and mobile-optimized consultation forms.
*   **Performance & Accessibility:** Targeting Google PageSpeed scores of 95+ and WCAG 2.1 AA+ compliance.

## Tech Stack

*   PHP 8.1+
*   Modern CSS (Grid, Flexbox, variables)
*   Vanilla JS
*   Gutenberg
*   REST API ready
