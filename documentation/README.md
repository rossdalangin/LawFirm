## Getting Started

### Installation

1.  Download the `legacy-pro-max.zip` file from your account.
2.  In your WordPress dashboard, go to **Appearance > Themes > Add New**.
3.  Click **Upload Theme** and select the `legacy-pro-max.zip` file.
4.  Click **Install Now**.

### Theme Activation

Once the theme is installed, click **Activate**.

### One-Click Demo Import

To import the demo content for one of the six Firm Archetypes:

1.  Install and activate the [One Click Demo Import](https://wordpress.org/plugins/one-click-demo-import/) plugin.
2.  Go to **Appearance > Import Demo Data**.
3.  Choose the archetype you want to import and click **Import**.

## Theme Options

All theme options can be found in the WordPress Customizer (**Appearance > Customize**).

### Firm Archetypes

Select one of the six pre-designed Firm Archetypes to instantly apply a unique design system to your site, including colors, typography, and spacing.

### Legal Compliance

Configure legal disclaimers, such as the "Attorney Advertising Notice," to ensure compliance with local regulations.

### Conversion Tools

Enable and configure conversion-focused tools like the exit-intent modal to capture more leads.
